# 📊 Параметры анализа акций

## Целевая дивидендная доходность (dividend_target_pct)

### Что это?
Минимальная дивидендная доходность, при которой генерируется бычий сигнал `DY_GT_TARGET`.

### Рекомендуемое значение
**Ставка ЦБ России или выше** (на 2026 год: ~13-15%)

### Как используется?
- Если дивидендная доходность акции ≥ `dividend_target_pct`, генерируется сигнал `DY_GT_TARGET`
- Этот сигнал увеличивает score рекомендации и может привести к рекомендации **BUY**

### Пример
Если `dividend_target_pct = 13%`:
- Акция с DY = 15% → сигнал `DY_GT_TARGET` ✅
- Акция с DY = 10% → сигнала нет ❌

## Окна SMA (Simple Moving Average)

### Что это?
Периоды для расчёта простых скользящих средних — средние цены закрытия за указанное количество дней.

### Стандартные значения
- **20** — краткосрочный тренд (1 месяц торговли)
- **50** — среднесрочный тренд (~2.5 месяца)
- **200** — долгосрочный тренд (~1 год)

### Как используются?

#### SMA20 (20 дней)
- **Назначение:** Краткосрочный тренд
- **Использование:** Оценка краткосрочного движения цены
- **Сигналы:** Тренд вверх/вниз за последние 20 дней

#### SMA50 (50 дней)
- **Назначение:** Среднесрочный тренд
- **Использование:** Определение пересечений с SMA200
- **Сигналы:**
  - **"Золотой крест"** (SMA50 пересекает SMA200 снизу вверх) → бычий сигнал
  - **"Крест смерти"** (SMA50 пересекает SMA200 сверху вниз) → медвежий сигнал

#### SMA200 (200 дней)
- **Назначение:** Долгосрочный тренд
- **Использование:** Определение недооценённости/переоценённости
- **Сигналы:**
  - Цена **ниже** SMA200 → сигнал `PRICE_BELOW_SMA200` (бычий, акция недооценена)
  - Цена **выше** SMA200 → сигнал `PRICE_ABOVE_SMA200` (медвежий, акция переоценена)

### Влияние на рекомендации

Система использует SMA для:
1. **Оценки дисконта/премии:**
   - Если цена на 10%+ ниже SMA200 → увеличивает score (потенциальная покупка)
   - Если цена на 10%+ выше SMA200 → уменьшает score (потенциальная продажа)

2. **Определения тренда:**
   - Краткосрочный тренд (SMA20) влияет на confidence
   - Пересечения SMA50/SMA200 дают сильные сигналы

3. **Генерации сигналов:**
   - `PRICE_BELOW_SMA200` — бычий сигнал
   - `PRICE_ABOVE_SMA200` — медвежий сигнал
   - `SMA50_CROSS_UP_SMA200` — "Золотой крест"
   - `SMA50_CROSS_DOWN_SMA200` — "Крест смерти"

## Пауза между тикерами (rate_limit)

### Что это?
Задержка между запросами к MOEX API для одного тикера.

### Рекомендуемое значение
**0.4 секунды** (по умолчанию)

### Зачем?
Защита от превышения лимитов запросов к MOEX API. При слишком частых запросах API может вернуть ошибку 429 (Too Many Requests).

## Примеры настроек

### Консервативная стратегия (низкий риск)
```
dividend_target_pct: 15.0  # Высокий порог дивидендов
sma_windows: [20, 50, 200]  # Стандартные окна
```

### Агрессивная стратегия (высокий риск)
```
dividend_target_pct: 10.0  # Ниже ставки ЦБ
sma_windows: [20, 50, 200]  # Стандартные окна
```

### Дивидендная стратегия
```
dividend_target_pct: 13.0  # Как ставка ЦБ
sma_windows: [20, 50, 200]  # Стандартные окна
```
