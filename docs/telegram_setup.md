# Настройка Telegram-уведомлений

## 📱 Быстрый старт

### 1. Создание Telegram-бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен бота (например: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)
4. Сохраните токен

### 2. Получение Chat ID

1. Найдите [@userinfobot](https://t.me/userinfobot) в Telegram
2. Отправьте команду `/start`
3. Бот вернёт ваш Chat ID (например: `123456789`)
4. Сохраните Chat ID

### 3. Настройка переменных окружения

Создайте файл `.env` в корне проекта (или обновите существующий):

```env
TELEGRAM_BOT_TOKEN=your_bot_token_here
TELEGRAM_CHAT_ID=your_chat_id_here
```

**Важно:** Не коммитьте `.env` в git! Он уже в `.gitignore`.

### 4. Установка зависимостей

```bash
pip install python-telegram-bot
```

Или обновите requirements.txt:

```bash
pip install -r requirements.txt
```

### 5. Проверка подключения

После запуска сервера система автоматически попытается инициализировать Telegram-бота. Проверьте логи:

```
Telegram bot initialized successfully
```

Если видите ошибку, проверьте:
- Правильность токена
- Правильность Chat ID
- Установлен ли `python-telegram-bot`

## 🔔 Как это работает

### Автоматические уведомления

Система автоматически:
1. **Каждые 3 часа** обновляет данные по инструментам из вашего портфеля
2. **Сравнивает** текущие цены с ценами 3 и 24 часа назад
3. **Генерирует сигналы** при значимых изменениях:
   - Снижение цены > 3% → "можно докупать"
   - Рост цены > 3% → "можно продавать"
4. **Отправляет уведомления** в Telegram

### Формат уведомлений

```
📉 SBER: Цена снизилась на 4.2%
💰 Было: 280.50₽ → Стало: 268.50₽
📊 Объём: 2.3x от среднего (высокий)
📈 RSI: 28.5 (перепроданность)
💡 Можно докупать (падение цены + высокий объём)
⏰ Время: 13:45 МСК (3ч назад)
🟡 Приоритет: MEDIUM
```

### Приоритеты сигналов

- **🔴 HIGH**: Изменение > 5% + высокий объём
- **🟡 MEDIUM**: Изменение 3-5% + высокий объём, или изменение > 5%
- **🟢 LOW**: Изменение 3-5%

## ⚙️ Настройка

### Изменение порогов

Отредактируйте `config/monitoring.yaml`:

```yaml
monitoring:
  price_change_threshold_pct: 3.0  # Минимальное изменение для уведомления
  volume_spike_threshold: 2.0  # Порог всплеска объёма
```

### Интервал обновления

```yaml
monitoring:
  update_interval_hours: 3  # 3 или 4 часа
```

### Фильтр по приоритету

```yaml
notifications:
  min_priority: "MEDIUM"  # Только HIGH и MEDIUM сигналы
```

### Группировка уведомлений

```yaml
notifications:
  group_notifications: true  # Одно сообщение с несколькими сигналами
```

## 🛠️ Отладка

### Проверка подключения

Если уведомления не приходят:

1. **Проверьте логи:**
   ```
   Telegram bot initialized successfully
   ```

2. **Проверьте переменные окружения:**
   ```bash
   echo $TELEGRAM_BOT_TOKEN
   echo $TELEGRAM_CHAT_ID
   ```

3. **Проверьте, что бот запущен:**
   - Отправьте `/start` вашему боту в Telegram
   - Бот должен ответить

### Типичные ошибки

**"Telegram bot not initialized"**
- Проверьте токен и Chat ID
- Убедитесь, что `python-telegram-bot` установлен

**"Error sending Telegram notification"**
- Проверьте, что бот не заблокирован
- Убедитесь, что Chat ID правильный

## 📊 Что отслеживается

Система отслеживает изменения:
- **Цены** (сравнение с 3 и 24 часами назад)
- **Объёма торгов** (всплески > 2x от среднего)
- **RSI индикатора** (перекупленность/перепроданность)
- **Адаптивные пороги** (разные для акций и облигаций)

---

## 🎯 Рекомендации

1. **Начните с высоких порогов** (5%), чтобы не получать слишком много уведомлений
2. **Используйте фильтр по приоритету** (только HIGH/MEDIUM)
3. **Группируйте уведомления** для удобства
4. **Проверяйте логи** при проблемах

---

## 🔄 Отключение уведомлений

Чтобы временно отключить уведомления:

1. Удалите или закомментируйте переменные в `.env`:
   ```env
   # TELEGRAM_BOT_TOKEN=...
   # TELEGRAM_CHAT_ID=...
   ```

2. Или установите в `config/monitoring.yaml`:
   ```yaml
   telegram:
     enabled: false
   ```

Система продолжит работать, но уведомления отправляться не будут.
