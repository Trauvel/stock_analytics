# 📱 Настройка Telegram уведомлений

## Быстрый старт

### 1. Создание бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям (укажите имя и username бота)
4. BotFather даст вам токен в формате: `USER_ID:TOKEN`
   - Пример: `7348301143:AAGKsH8fo2oUjFC20hnJcmu9zn8JRkc_61c`

### 2. Получение Chat ID

#### Вариант 1: Автоматически (рекомендуется)

1. Найдите вашего бота в Telegram (по username, который вы указали)
2. Напишите боту `/start`
3. Запустите скрипт:
   ```powershell
   python get_telegram_chat_id.py
   ```
4. Скрипт покажет ваш Chat ID

#### Вариант 2: Вручную

1. Найдите вашего бота в Telegram
2. Напишите боту `/start`
3. Найдите бота [@userinfobot](https://t.me/userinfobot)
4. Отправьте ему `/start`
5. Он покажет ваш User ID - это и есть Chat ID для личных сообщений

### 3. Настройка .env файла

Откройте `.env` файл и добавьте:

```env
# Полный токен от BotFather (формат: USER_ID:TOKEN)
TELEGRAM_BOT_TOKEN=7348301143:AAGKsH8fo2oUjFC20hnJcmu9zn8JRkc_61c

# Chat ID (для личных сообщений = ваш User ID)
TELEGRAM_CHAT_ID=7348301143
```

### 4. Проверка

1. Перезапустите сервер
2. В логах должно появиться:
   ```
   Telegram bot verified: @your_bot_username (Bot Name)
   Telegram bot initialized successfully
   Chat access verified: private - Your Name
   Startup notification sent to Telegram
   ```
3. Вы должны получить сообщение в Telegram: "🚀 Stock Analytics Server - Сервер успешно запущен..."

## Типы чатов

### Личные сообщения (Private)

- **Chat ID**: Ваш User ID (число, например: `7348301143`)
- **Как получить**: Напишите боту `/start`, затем запустите `get_telegram_chat_id.py`
- **Преимущества**: Просто, не нужно добавлять бота в группы

### Группы (Group)

- **Chat ID**: Отрицательное число (например: `-1001234567890`)
- **Как получить**: Добавьте бота в группу, затем запустите `get_telegram_chat_id.py`
- **Требования**: Бот должен быть участником группы

### Каналы (Channel)

- **Chat ID**: Отрицательное число с префиксом `-100` (например: `-1001234567890`)
- **Как получить**: Добавьте бота как администратора канала, затем запустите `get_telegram_chat_id.py`
- **Требования**: Бот должен быть администратором канала

## Решение проблем

### Ошибка: "Not Found" или "chat not found"

**Причины:**
1. Неправильный Chat ID
2. Бот не добавлен в чат/канал
3. Для каналов: бот не является администратором
4. Бот был удалён из чата

**Решение:**
1. Проверьте Chat ID через `get_telegram_chat_id.py`
2. Убедитесь, что написали боту `/start` (для личных сообщений)
3. Для каналов: добавьте бота как администратора

### Ошибка: "Unauthorized" или "invalid token"

**Причины:**
1. Неправильный токен
2. Токен был отозван

**Решение:**
1. Проверьте, что токен полный (формат: `USER_ID:TOKEN`)
2. Получите новый токен через @BotFather командой `/token`

### Ошибка: "Forbidden" или "bot was blocked"

**Причины:**
1. Пользователь заблокировал бота
2. Бот был удалён из группы/канала

**Решение:**
1. Разблокируйте бота
2. Добавьте бота обратно в группу/канал

## Тестирование

После настройки можно протестировать отправку сообщений:

```python
from app.infrastructure.telegram.notifier import TelegramNotifier

notifier = TelegramNotifier()
if notifier.is_enabled():
    notifier.send_test_message()
    print("Тестовое сообщение отправлено!")
else:
    print("Бот не инициализирован")
```
