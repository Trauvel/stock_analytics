# 📥 Импорт портфеля из отчётов Сбера

## Описание

Функция импорта позволяет автоматически загрузить позиции и кеш из HTML отчётов брокера Сбера в портфель системы.

## Как использовать

### Через веб-интерфейс

1. Откройте страницу настроек: `/static/settings.html`
2. Перейдите на вкладку "💼 Портфель"
3. В разделе "📥 Импорт из отчёта Сбера":
   - Нажмите "Выбрать файл" и выберите HTML отчёт Сбера
   - Выберите опцию "Объединить с существующими позициями" (если нужно)
   - Нажмите "📥 Импортировать из Сбера"
4. После успешного импорта позиции и кеш будут обновлены

### Через API

```bash
curl -X POST "http://localhost:8000/api/portfolio/import/sber-html" \
  -F "file=@sber-data/42340C9_23012026.html" \
  -F "merge=true"
```

**Ответ:**
```json
{
  "ok": true,
  "message": "Импортировано 13 позиций, кеш: 8735.44 RUB"
}
```

### Через код

```python
from app.application.dependencies import container
import asyncio

use_case = container.import_sber_html_use_case()

portfolio = asyncio.run(
    use_case.execute(
        html_file_path="sber-data/42340C9_23012026.html",
        merge_with_existing=True
    )
)

print(f"Импортировано {len(portfolio.positions)} позиций")
```

---

## Что импортируется

### Позиции

Из HTML отчёта извлекаются:
- **Тикер** (символ инструмента)
- **Количество** (из колонки "Конец периода")
- **Рыночная цена** (из колонки "Конец периода")
- **Валюта** (обычно RUB)
- **Тип инструмента** (stock, bond, etf, currency)
- **ISIN** (сохраняется в заметках)

### Кеш

Извлекается "Исходящий остаток" из раздела денежных средств.

---

## Особенности

### Определение тикеров

Парсер автоматически определяет тикеры из названий:
- **Акции**: "Сбербанк" → `SBER`, "МосБиржа" → `MOEX`
- **ETF**: "SBGB ETF" → `SBGB`
- **Облигации**: Название используется как есть (например, "Абрау2P-01")

### Объединение позиций

При `merge=true`:
- Существующие позиции с тем же тикером **заменяются** новыми данными
- Новые позиции **добавляются**
- Кеш **обновляется** на значение из отчёта

При `merge=false`:
- Весь портфель **заменяется** данными из отчёта

---

## Поддерживаемые форматы

- HTML отчёты брокера Сбера
- Отчёты с позициями на "Фондовом рынке"
- Отчёты с денежными средствами в RUB

---

## Ограничения

1. **Тикеры облигаций**: Для облигаций с кириллическими названиями используется полное название (не стандартный тикер)
2. **Валюты**: Поддерживается только RUB (можно расширить)
3. **Средняя цена**: Используется текущая рыночная цена как средняя цена покупки

---

## Примеры

### Импорт с объединением

```python
# Объединяет с существующим портфелем
portfolio = await use_case.execute(
    html_file_path="sber-data/report.html",
    merge_with_existing=True
)
```

### Полная замена портфеля

```python
# Заменяет весь портфель
portfolio = await use_case.execute(
    html_file_path="sber-data/report.html",
    merge_with_existing=False
)
```
