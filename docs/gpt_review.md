## 1️⃣ Почему ВСЕ = HOLD

Ты сейчас фактически задал такие условия BUY, что они **почти недостижимы одновременно**:

### Текущая логика (по отчёту ):

BUY возможен только если:

* цена **выше / около SMA200**
* **нет нисходящего тренда**
* **нет перекоса по дивидендам**
* **не у верхов 52W**
* score > порога

А рынок сейчас:

* боковой / слегка нисходящий
* большинство бумаг **около SMA200**
* почти везде тренд −0.5…−2%

👉 В такой фазе **BUY не бывает**, это нормально.

---

## 2️⃣ Почему даже золото (TGLD) = HOLD

Разберём конкретно **TGLD** — хороший пример.

По данным:

* цена **чуть выше SMA200**
* но:

  * `✗ Нисходящий тренд -2.2%`
  * нет дивидендов (для акций ты это штрафуешь)
* score = **−1.1**

### Логическая ошибка

Ты **применяешь акционную логику к защитному активу**.

Для золота:

* дивиденды **не должны учитываться вообще**
* краткосрочный тренд **вторичен**
* важен:

  * выше SMA200
  * макроконтекст (инфляция / риск)

👉 Поэтому TGLD и «наказывают» ни за что.

### Пример для TGLD

* выше SMA200 → +
* защитный актив → +

### Пример для X5

👉 **ACCUMULATE**

### Пример для условного MOEX

* около SMA200
* без явных триггеров

👉 **HOLD**

## 7️⃣ Минимальные правки формулы (без переписывания всего)

### 1. Ввести тип актива

```yaml
asset_type:
  equity
  bond
  fund
  commodity
```

И:

* commodity → не штрафовать за DY
* bond → вообще убрать SMA и тренды
* fund → мягкие коэффициенты

---

### 2. Ослабить BUY, но ввести ACCUMULATE

Например:

* BUY: score ≥ +2.0
* ACCUMULATE: score ≥ +0.5
* HOLD: −1.0 … +0.5
* AVOID: < −1.0

---

### 3. Добавить портфельный контекст

Если актив уже есть в портфеле:

* BUY → ACCUMULATE
* HOLD → HOLD (но с пометкой «докупать можно»)

## Внесённые правки (по отзыву)

* **Четыре уровня действий**: введены **BUY** (агрессивно покупать), **ACCUMULATE** (докупать понемногу), **HOLD**, **AVOID** (не докупать / сократить), **SELL**. Пороги: BUY ≥ 2.0, ACCUMULATE ≥ 0.5, HOLD между −1.0 и +0.5, AVOID ≤ −1.0, SELL ≤ −2.0.
* **Тип актива**: учёт **commodity** (например TGLD) и **fund**. Для commodity не штрафуем за отсутствие DY и даём бонус за цену выше SMA200; тренд учитывается с меньшим весом (0.4 вместо 0.8). Для fund не штрафуем за низкие дивиденды, тренд — мягче.
* **Конфиг**: в `config/reco.yaml` добавлены `accumulate_score_min`, `avoid_score_max`, `commodity_tickers: ["TGLD"]`, `fund_tickers`. При BUY с ценой ниже SMA200 без сильного фундамента рекомендация понижается до **ACCUMULATE**.
* **Дашборд**: в блоке рекомендаций отображаются счётчики и фильтры для всех пяти действий (Покупать, Докупать, Держать, Не докупать, Продавать).
