## Внесённые правки

* **Контекст рынка (market_regime)**: в `config/reco.yaml` добавлен параметр `market_regime: sideways | bull | bear`. При **bull** к score для выбора действия добавляется +0.25 (чаще получается ACCUMULATE), при **bear** — −0.25 (усиливается REDUCE). При **sideways** поведение без изменений.
* **Два типа HOLD**: вместо одного HOLD введены **HOLD_STRONG** («держать; можно докупать при просадках») и **HOLD_NEUTRAL** («ничего не делаем»). HOLD_STRONG выставляется при score ≥ 0.2 или при цене выше SMA200 и тренде не хуже −2%. В дашборде — отдельные счётчики и фильтры, разный цвет (синий / серый).
* **Commodity (TGLD)**: для защитного актива **полностью отключён штраф за нисходящий тренд** (вес 0); за восходящий по-прежнему добавляется бонус. В обосновании при нисходящем тренде выводится «commodity — без штрафа».
