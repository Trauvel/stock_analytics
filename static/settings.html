Параметры анализа
ℹ️ Справка: Эти параметры влияют на генерацию торговых сигналов и рекомендаций. Подробнее о параметрах →
Рекомендуется: ставка ЦБ или выше (сейчас ~13-15%)
Использование: Если дивидендная доходность акции ≥ этого значения, генерируется бычий сигнал DY_GT_TARGET
Что это: Периоды для расчёта простых скользящих средних (SMA)
Влияние:
• SMA20 (20 дней) — краткосрочный тренд, используется для оценки краткосрочного движения цены
• SMA50 (50 дней) — среднесрочный тренд, используется для определения "Золотого креста" и "Креста смерти" (пересечение с SMA200)
• SMA200 (200 дней) — долгосрочный тренд, используется для определения недооценённости/переоценённости акции (цена ниже/выше SMA200 = бычий/медвежий сигнал)
Rate limit для MOEX API (защита от превышения лимитов запросов)
